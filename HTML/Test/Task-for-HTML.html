Basics of Web Development

What is Browser?

  • A browser is a software application used to open and view websites on the internet.
  • It reads HTML, CSS, and JavaScript code and displays webpages to users.
  • Examples : Google Chrome and Microsoft Edge

What is Website?

  • A website is a collection of web pages connected together and available on the internet.
  • People can open a website using a browser.
  • Examples : Google and amazon

What is Static and dynamic website?
A static website is a website where the content is fixed and does not change for every user. It is created using HTML and shows the same information to all users. and example : A simple company website or personal portfolio page.
A dynamic website is a website where the content changes based on user or data. It uses database and programming languages. and example : YouTube, Facebook, Amazon.

what is webpage?
A webpage is a single page of a website displayed in a browser. like Home page and about page etc.,

What is http?

What are Activity Attributes (Behavior-related attributes)
These attributes control what happens or how the element behaves.
The type attribute is an activity attribute used to define how the input behaves like text box, password box, or checkbox. The disabled attribute is an activity attribute used to make an element inactive so user cannot click or edit it. The readonly attribute is an activity attribute used to allow viewing but not editing the input field. The autofocus attribute is an activity attribute used to automatically place cursor in input field when page loads. The autocomplete attribute is an activity attribute used to enable or disable browser suggestions while typing.

What is Validation Attributes?
These attributes are used to check user input before submission. and Examples are The required attribute is a validation attribute used to make input mandatory before form submission. The pattern attribute is a validation attribute used to check input using rules like regular expressions. The min and max attributes are validation attributes used to set minimum and maximum allowed values. The maxlength attribute is a validation attribute used to limit number of characters entered. The type="email" attribute is a validation feature used to ensure correct email format. The type="number" attribute is a validation feature used to allow only numeric values.

What is the select tag in HTML?
The select tag is used in HTML forms to create a drop-down list, where users can choose one or more options.

What tags used with select tags

  • The select tag is used to create a dropdown list.
  • The option tag used to define each item inside the dropdown.
  • The optgroup tag is used to group related options inside a dropdown.

What are Attributes of select tag?
The name attribute is used to identify the selected value when submitting form data. The multiple attribute is used to allow selecting more than one option. The size attribute is used to show multiple options at once in list form. The disabled attribute is used to make the dropdown inactive. The required attribute is used to make selection mandatory before submitting form. The autofocus attribute is used to automatically focus the dropdown when page loads.

What is the option tag in HTML?
The value attribute is used to send selected data to the server. The selected attribute is used to set a default selected option. The disabled attribute is used to disable a specific option.

Data Projection

What is Data projection?
Data projection is the method of organizing and displaying data in a readable format like tables, charts, or graphs.
Data is often projected using: tables and ul ol list

What is table tag in HTML?
The table tag is used to represent data in rows and columns.

Why table is used?

  • To organize data clearly
  • To show records (like marks, list, prices)
  • To make data easy to read

Tags used in Table :
The table tag is used to create a table structure.
The table row tag is used to create a row in the table.
The table heading tag is used to define header cells.
The table data tag is used to store actual data in cells.
The caption tag is used to give title to a table.

HTML5

What is Doctype html
!DOCTYPE html is called the document type declaration. It tells the browser that the webpage is written in HTML5. Without DOCTYPE, browsers may enter quirks mode and render the webpage incorrectly.

What are Meta Tags?
Meta tags provide information about the webpage to browsers, search engines, and external services. These tags are written inside the head section and are not visible directly on the webpage.

What is UTF?
Unicode Transformation Format

What is Favicon?
Favicon is the small icon shown in the browser tab near the webpage title.

What are Open Graph (OG) Properties?
OG properties are meta tags used for social media sharing. When links are shared on platforms like Facebook or LinkedIn, OG tags control how the preview appears.

What is Audio Tag?
The audio tag is used to embed audio files inside webpages.

What is Video Tag?
The video tag is used to embed videos directly inside webpages.

What is iframe?
The iframe tag is used to embed another webpage inside the current webpage.

What is HTML5?
HTML5 is the latest version of HTML introduced to improve multimedia support, semantic structure, and web application capabilities.
