CSS Concepts

CSS is to design your webpage layout and style and it is helping for making a webpage looking good and user friendly design

Layout

layout is the design of your webpage it decide which content in which place to shown on your screen

Cascading

it is a multiple styles can apply to single element and browser decides which style should win

CSS Styling

CSS Styling means applying visual designs such as colors, backgrounds, fonts, layouts, animations, and effects to HTML elements

Types of CSS

  • Inline css
  • Internal css
  • External css

CSS Pirority order

Browser reads style this orderwise

CSS Specificity

Specificity is the Pirority calculation system used by browser to determine which css rule should apply when multiple styles are rules target at the same element

Selectors

Selectors are used to target HTML elements and apply styles.

  • * - Universal Selector
  • . - class Selector
  • # - id selector
  • , - group selector
  • space - Descendant selctor
  • div>p - child selector
  • attribute selector

Typography

It is a test design like font size and font family and font weight

Box Model

The box model consists of margin, border, padding, and content.

Flex

Flex is one dimenisional layout it works row or coloum to make a responsive webpage layout and flex is helping to split the webpages and align the context row or coloum vias and flex is the most used layout system in css

CSS Units

CSS units are used to define the size of elements text, spacing, width, height, marign, border, padding and layout inside a webpage and without unit browser can't understand the how much size and spacing applied to element

Types of Units

  • Absolute unit that is pixel(px)
  • Relative unit are persentage(%), EM and REM units.

Grid

Grid is a two dimensional layout we can design row and coloum vias at same time and we can create a complex responsive layout using grid mainly we use grid for dashboard layouts website section cards design and gallary layout

Pseudo Classes

it is a special keyword in css use to define a special state in html element so it also developers to apply style when certain user interaction. pseudo class are widely used modern frontent development symbole is : colon. they are :hover, :focus and :active are common pseudo-classes.

Pseudo Element

It is use to style specific part of an html element instead of the entire element they are written using double :: colon they are ::before, ::After, ::First letter, :: First Line, :: Selection

Animations

It is a property visually manipulate the html element without affecting document page and it properties are transform and transition

  • transform value are translate, skew, rotate, scale.
  • transition values are ease, linear, ease-in, ease-out, ease-in-out

Position

Position is one of most important css property used in frontend development it controls how an element displace inside the element by default all html element follow the normal document flow and some elements appear one below another from top to bottom

Values of Position are relative and Absoluteand fixed and sticky

Media Query

media query is concept used in responsive webdesign and its allows developers to apply difference css style based on screen width and screen height device type. orientation landscape and portarit
