JS Variables

1. What is Variable?

A variable is a container used to store data values in a program. Example: 

let studentName = "Dharan";

2. What is Declaration?

Declaration means creating a variable using var, let, or const. Example: 

let studentName;

3. What is Initialization?

Initialization means assigning a value to a variable. Example: 

let studentName = "Dharan";

4. What are the 3 Types of Keywords?

JavaScript provides three keywords for declaring variables:

  • var
  • let
  • const

5. What is the Compiler in JavaScript and its Name?

JavaScript is mainly executed by a JavaScript Engine. Different browsers use different engines:

  • Google Chrome → V8 Engine
  • Mozilla Firefox → SpiderMonkey
  • Safari → JavaScriptCore

The most popular JavaScript engine is V8 Engine.

6. What is a Printing Statement?

A printing statement is used to display output. In JavaScript, the most common printing statement is: 

console.log("Hello World");

Output: 

Hello World
