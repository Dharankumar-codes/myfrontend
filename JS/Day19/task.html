DOM & React Assignment

1. What is DOM?

DOM means Document Object Model. It connects HTML and JavaScript. With DOM, we can change text, images, styles, and other elements on a webpage without reloading the page.

2. What is React?

React is a JavaScript library used for creating modern web applications. It helps developers build user interfaces using reusable parts called components.

3. What is a Component?

A component is a small section of a webpage that can be reused. For example, a navbar, button, or footer can be created once and used in many places.

4. What is a Function?

A function is a set of instructions written to perform a task. Instead of writing the same code again and again, we can put it inside a function and call it whenever needed.
