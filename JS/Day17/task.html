1. Callback Function

A callback is a function that is passed into another function and executed later when a particular task is completed.

  • Helps control the order of execution.
  • Used in asynchronous operations.
  • Allows one function to trigger another.

2. Promise

A Promise represents the result of an asynchronous operation. It can be pending, fulfilled, or rejected.

  • Reduces nested callbacks.
  • Makes code more manageable.
  • Provides easier error handling.

3. Async / Await

Async and Await are modern JavaScript features that simplify working with Promises.

  • Improves code readability.
  • Looks similar to normal synchronous code.
  • Useful for handling multiple asynchronous tasks.

4. Fetch API

The Fetch API is used to send requests to a server and receive responses from an API.

  • Retrieve information from a server.
  • Create new records.
  • Modify existing data.
  • Remove unwanted data.
