 What is DOM? (Document Object Model)

Introduction
When a browser loads an HTML page, it does not directly understand HTML tags like:

<h1>Hello</h1>

<button>Click</button>
Instead, the browser converts the HTML document into a JavaScript object structure called the DOM (Document Object Model).

DOM acts as a bridge between:

HTML

↓

DOM

↓

JavaScript
Without DOM, JavaScript cannot access or modify HTML elements.

Why Do We Need DOM?
HTML alone can only display content.

JavaScript + DOM can:

Change Text

Change Images

Change Colors

Hide Elements

Show Elements

Handle Button Clicks

Create Dynamic UI

Handle Forms
Example:

<h1 id="title">Welcome</h1>
document.getElementById("title").innerText =
"Hello Sudhan";
Output:

<h1>Hello Sudhan</h1>
JavaScript changed HTML using DOM.

Browser Loading Process
Step 1
Browser reads HTML.

<body>

   <h1>Hello</h1>

   <button>Click</button>

</body>
Step 2
Browser creates DOM Tree.

Document

└── html

    └── body

        ├── h1

        └── button
Step 3
JavaScript accesses DOM.

document.querySelector("h1")
Step 4
JavaScript updates DOM.

document.querySelector("h1").innerText =
"Updated";
Browser automatically updates UI.

What is document?
The browser provides a global object:

document
This object represents the entire HTML page.

console.log(document);
Output:

Entire HTML Document

Event Listener
What is Event Listener?
Event Listener waits and listens for an event.

Think:

Security Guard

↓

Waiting

↓

Something Happens

↓

Action Performed
Syntax
element.addEventListener(

   "event",

   callbackFunction

);
Example
HTML
<button id="btn">
   Click
</button>
JS
const btn =

document.getElementById(
   "btn"
);

btn.addEventListener(

   "click",

   ()=>{

      console.log(
         "Button Clicked"
      );

   }

);
Output

Button Clicked
Why Event Listener?
Without Event Listener:

console.log(
   "Button Clicked"
);
Runs immediately.

With Event Listener:

btn.addEventListener(
   "click",
   ()=>{
      console.log(
         "Button Clicked"
      );
   }
);
Runs only after click.
