🚀 Fetch API - Interview Notes (Detailed Explanation)

What is Fetch API?
Fetch API is a modern JavaScript function used to communicate with servers and APIs. It allows a frontend application to send HTTP requests and receive data from a backend server without reloading the entire page. Before Fetch API, developers commonly used XMLHttpRequest (XHR), which was more complex and difficult to maintain. Fetch API provides a cleaner, Promise-based approach to handling asynchronous operations. Today, almost every modern application such as Facebook, Instagram, Amazon, Netflix, and Gmail uses API communication to retrieve and update data dynamically. Whenever a user logs in, views products, loads profiles, searches data, or submits forms, Fetch API is often involved behind the scenes.

Basic Example
fetch("https://jsonplaceholder.typicode.com/users")
.then(response => response.json())
.then(data => {
   console.log(data);
});
🚀 Why Do We Use Fetch API?
The primary purpose of Fetch API is to exchange data between the frontend and backend. Without APIs, web applications would be static and unable to retrieve live data from databases. Fetch enables applications to request data from a server, receive responses, and update the user interface dynamically. Instead of refreshing the entire webpage every time new data is needed, Fetch updates only the required portion of the page. This improves performance, user experience, and application responsiveness. Modern Single Page Applications (SPA) built with React, Angular, Vue, and Next.js heavily rely on Fetch or similar libraries like Axios.

🚀 How Fetch API Works Internally?
When a user performs an action such as clicking a button, JavaScript uses Fetch API to send a request to a server. The server receives the request, processes it, interacts with the database if necessary, and sends a response back. The response is usually returned in JSON format. JavaScript then converts the JSON data into objects or arrays and updates the DOM dynamically. This entire process happens asynchronously, meaning the browser remains responsive while waiting for the server response.

🚀 Why is Fetch Asynchronous?
API communication takes time because data must travel through the internet, reach the server, process requests, access databases, and return results. If JavaScript waited synchronously for every request, the browser would freeze until the response arrived. To prevent this, Fetch works asynchronously using Promises. JavaScript sends the request and continues executing other code. Once the response arrives, Fetch notifies JavaScript and executes the appropriate callback, Promise, or Async/Await logic.

Example
console.log("Start");

fetch("https://jsonplaceholder.typicode.com/users")
.then(response => response.json())
.then(data => {
   console.log(data);
});

console.log("End");

This proves Fetch is asynchronous because JavaScript does not wait for the API response before executing the next line.

🚀 Why Do We Use response.json()?
When a server sends data back to the browser, the data is usually in JSON (JavaScript Object Notation) format. JavaScript cannot directly use this raw JSON response. The response.json() method converts the JSON response into JavaScript arrays or objects so that developers can access and manipulate the data easily.

Example
const response = await fetch(url);

const users = await response.json();
After conversion:

[
   {
      id:1,
      name:"Leanne Graham"
   }
]
Now JavaScript can access:

users[0].name
🚀 Fetch API Using Async/Await
Modern JavaScript projects commonly use Async/Await with Fetch because it makes asynchronous code easier to read and maintain. Instead of chaining multiple .then() methods, developers can use await to pause execution until the Promise is resolved. This makes the code look similar to synchronous code while still maintaining asynchronous behavior. Async/Await is now the preferred approach in React, Node.js, Express, and MERN Stack applications.

Example
const getUsers = async()=>{

   const response = await fetch(
      "https://jsonplaceholder.typicode.com/users"
   );

   const users = await response.json();

   console.log(users);

};

getUsers();
🚀 Fetch API and DOM
One of the most common uses of Fetch API is displaying data inside HTML tables, cards, dashboards, and forms. After receiving data from an API, JavaScript loops through the data and dynamically creates HTML content. This allows applications to display real-time information without requiring a page refresh. Most admin dashboards, CRM systems, HR portals, e-commerce platforms, and student management systems follow this approach.

🚀 Fetch API Interview Answer
What is Fetch API?

Fetch API is a modern JavaScript function used to send HTTP requests and receive responses from servers asynchronously. It is Promise-based, supports Async/Await, and is commonly used to retrieve, create, update, and delete data from APIs without reloading the webpage.

Why do we use Fetch API?

We use Fetch API to communicate between the frontend and backend, retrieve data from databases, update user interfaces dynamically, and build modern interactive web applications.

Why is Fetch asynchronous?

Because API requests take time to travel over the network. JavaScript sends the request and continues executing other code while waiting for the server response.

Why do we use response.json()?

Because servers usually return data in JSON format, and response.json() converts that JSON into JavaScript objects or arrays that can be used in the application.
