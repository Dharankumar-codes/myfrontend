What is Register?

A Register page is used to collect a new user's information and create a new account. During registration, the application takes details such as the user's name, email, password, and role, validates the input, and stores the information for future login. In our DOM project, we store this information inside an Array of Objects and save it in localStorage, so the data remains available even after refreshing the browser.

Why Do We Use Registration?
Registration is the first step of user authentication. Without registration, a user cannot create an account or access protected pages. Every application such as Instagram, Facebook, Amazon, and Gmail requires users to register before they can log in.

Each user is stored as an object.

   id:1,

   name:"Sudhan",

   email:"sudhan@gmail.com",

   password:"12345",

   role:"Admin"

All users are stored inside an array.

[
   {
      id:1,
      name:"Sudhan",
      email:"s@gmail.com",
      password:"123",
      role:"Admin"

   {
      id:2,
      name:"Rahul",

      password:"456",

   }

This is called an Array of Objects.

What is Login?
Login is the process of verifying a user's identity. The application compares the email and password entered by the user with the stored data. If both values match, the user is authenticated and allowed to access the application.

Why Do We Use Login?
Login protects application data from unauthorized users. Only registered users can access dashboards, profiles, orders, or other secure pages.

Why Do We Use localStorage?
Normally, JavaScript variables are stored in RAM (memory). When the page is refreshed, all variables are destroyed and the data is lost.
