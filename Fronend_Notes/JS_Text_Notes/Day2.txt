ES6 (ECMAScript 2015)

Why ES6 is Important?
Before ES6, JavaScript code was lengthy and difficult to maintain. ES6 introduced modern JavaScript.

Most React, Node.js, Angular, Vue projects use ES6+ features.

1. let & const
Why introduced?
To solve problems caused by:

var
because var has function scope and allows accidental redeclaration.

Example
let hero = "Vijay";

hero = "Ajith";

console.log(hero);
Output

Ajith
2. Arrow Functions
Why introduced?
Short syntax.

Cleaner callbacks.

Lexical this support.

Old Way
function add(a,b){

   return a+b;

}
ES6
const add = (a,b)=>{

   return a+b;

};

console.log(add(10,20));
Output

30
3. Template Literals
Why introduced?
Before ES6:

let hero = "Vijay";

console.log(
   "Hero Name is " + hero
);
ES6
let hero = "Vijay";

console.log(
   `Hero Name is ${hero}`
);
Output

Hero Name is Vijay
4. Destructuring
Why introduced?
Easy extraction from arrays and objects.

Example
const heroes = [

   "Vijay",

   "Ajith"

];

const [hero1,hero2] = heroes;

console.log(hero1);
Output

Vijay
5. Spread Operator (...)
Why introduced?
Copy and merge arrays/objects.

Example
const heroes1 = [

   "Vijay",

   "Ajith"

];

const heroes2 = [

   ...heroes1,

   "Suriya"
];

console.log(heroes2);
Output

[
 "Vijay",
 "Ajith",
 "Suriya"
]
6. Rest Operator (...)
Why introduced?
Receive multiple arguments.

Example
const total = (...numbers)=>{

   console.log(numbers);

};

total(10,20,30);
Output

[10,20,30]
