What is DOM?

DOM stands for Document Object Model.

When a browser loads an HTML page, it converts all HTML elements into JavaScript objects. This object structure is called the DOM. Using DOM, JavaScript can access, read, update, delete, hide, or show HTML elements dynamically without manually editing the HTML file.

Example
<h1>Hello</h1>
Browser converts it to:

Document
   ↓
html
   ↓
body
   ↓
h1
JavaScript can now access:

document.querySelector("h1")
Why Do We Use DOM?
Without DOM, JavaScript cannot communicate with HTML elements.

Using DOM we can:

Read User Input

Change Text

Change Images

Hide Elements

Show Elements

Validate Forms

Create Dynamic UI

Handle Events

Update Content Without Reloading
DOM Selectors
Selectors are used to find HTML elements.

getElementById()
Selects a single element using id.

Syntax
document.getElementById("idName")
Example
<h1 id="title">Welcome</h1>
document.getElementById("title")
querySelector()
Returns the first matching element.

Syntax
document.querySelector("selector")
Example
document.querySelector(".box")
querySelectorAll()
Returns all matching elements.

Syntax
document.querySelectorAll(".box")
DOM Properties
Properties are used to read or update element data.

innerText
Changes text content.

Example
heading.innerText =
"Hello JavaScript"
innerHTML
Changes HTML content.

Example
heading.innerHTML =
"<span>Hello</span>"
value
Used to get input values.

Example
input.value
src
Changes image source.

Example
image.src =
"hero.jpg"
href
Changes link URL.

Example
link.href =
"https://google.com"
style
Changes CSS dynamically.

Example
heading.style.color =
"red"

What is Event Listener?
Event Listener waits for an event and executes a function when the event occurs.

Syntax
element.addEventListener(

   "event",

   callbackFunction

)
Example
button.addEventListener(

   "click",

   ()=>{

      console.log(
         "Clicked"
      );

   }

)
Difference Between Event & Event Listener
Event
Action Happening
Example:

User Clicks Button
Event Listener
Waits for Event
Example:

button.addEventListener(
   "click",
   ()=>{
      console.log(
         "Clicked"
      );
   }
)
