🚀 React JS Notes (Basics to Components)

What is React JS?
React JS is an open-source JavaScript library developed by Meta Platforms for building fast, interactive, and reusable user interfaces. React follows a Component-Based Architecture where the UI is divided into small reusable components. Instead of updating the entire webpage, React updates only the changed part using a Virtual DOM, making applications faster and more efficient. Today, React is widely used for building Single Page Applications (SPA), dashboards, e-commerce applications, CRM systems, admin panels, and enterprise web applications.

Why React?
Before React, developers used pure JavaScript or jQuery to manipulate the DOM directly. As applications grew larger, managing UI updates became difficult and code became harder to maintain. React solves these problems by introducing reusable components, state management, Virtual DOM, and one-way data flow. React helps developers build scalable applications with better performance and maintainability.

What is a Component?
A Component is a reusable piece of UI. Instead of writing the same HTML multiple times, React allows developers to create components and reuse them wherever needed. Components make applications modular, maintainable, and easier to scale.

Example
function Header(){

   return <h1>Welcome</h1>;

}
Usage:

<Header />
Types of Components
Functional Component
A Functional Component is a JavaScript function that returns JSX. Modern React applications primarily use Functional Components because they support Hooks and have cleaner syntax.

Example
function App(){

   return <h1>Hello React</h1>;

}
Class Component
A Class Component is an ES6 class that extends React.Component. Before Hooks were introduced, Class Components were used for state and lifecycle methods. Today, Functional Components are preferred.

Example
import React,{Component} from "react";

class App extends Component{

   render(){

      return <h1>Hello React</h1>;

   }

}

export default App;
What is JSX?
JSX stands for JavaScript XML. JSX allows developers to write HTML-like syntax inside JavaScript. React converts JSX into JavaScript objects using Babel before rendering it in the browser. JSX makes React code easier to read and write.

Example
const element = <h1>Hello React</h1>;
Without JSX:

const element = React.createElement(
   "h1",
   null,
   "Hello React"
);

main.jsx
main.jsx is the entry point of a React application. It loads the App component and renders it inside the root element.

Example
import React from "react";
import ReactDOM from "react-dom/client";
import App from "./App";

ReactDOM.createRoot(
   document.getElementById("root")
).render(

   <App />

);
App.jsx
App.jsx is the root component of the application. All other components are generally rendered inside App.jsx.

Example
function App(){

   return(

      <h1>

         Welcome To React

      </h1>

   );

}

export default App;
